# Reyad Adhkar — Morning & Evening Adhkar App | أذكار الصباح والمساء

**Reyad Adhkar**, created by **Mohamed Reyad (@reyad-dev)**, is a lightweight web app for **morning and evening Adhkar (أذكار الصباح والمساء)** with an elegant Arabic-friendly interface, progress tracking, repetition counters, and separate morning/evening visual modes.

This project is useful for anyone looking for a simple **Islamic Adhkar website**, **Arabic Dhikr app**, or a clean front-end example built as a single-page HTML application.

## ✨ Features

- Morning Adhkar and Evening Adhkar modes
- Arabic-first Dhikr presentation with English UI support
- Repetition / target counters for individual supplications
- Progress tracking and reset controls
- Distinct morning and evening themes
- Mobile-friendly single-page layout
- Lightweight structure with no build step required

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Inline SVG / UI effects

## 🚀 Run Locally

Clone the repository and open `index.html` directly in your browser:

```bash
git clone https://github.com/reyad-dev/adhkar-morning-evening-app.git
cd adhkar-morning-evening-app
```

Then open `index.html`.
